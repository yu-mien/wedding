# 參考資料：網路上分享的婚禮網站 UI/UX 指令

> **狀態：僅供參考，尚未採用。**
> 這是在網路上找到、別人分享的婚禮網站生成指令。目前網站**不**照這份做；之後有需要時，再從裡面挑想要的部分，並明確指定要套用哪一段。
> 注意：裡面的色彩、表單欄位、選項文字都和目前網站不同。如果要採用表單相關內容，必須依 `CLAUDE.md` 的規則同步更新 Google 表單。

---

### 一、 視覺與設計風格
1. **字體搭配**：
   - 英文/數字：Google Fonts 的 'Cormorant Garamond'（優雅襯線體）。
   - 中文內文：Google Fonts 的 'Noto Serif TC'（思源宋體）。
2. **色彩主題（Morandi 溫潤莫蘭迪色調）**：
   - 主色（Primary）：`#d4a373`（暖焦糖金/奶茶色）。
   - 副色（Secondary）：`#8da399`（鼠尾草灰綠）。
   - 背景色（Background）：`#fdfaf7`（柔和米白奶油底色）。
   - 文字色：`#4a4a4a`。
   - LINE 綠色：`#06C755`。
3. **質感細節**：簡約排版、大字距（Tracking）、柔和陰影、毛玻璃效果（Backdrop-filter）、圓角按鈕與卡片。

---

### 二、 頁面結構與必備區塊

1. **開場歡迎儀式遮罩（Welcome Overlay）**：
   - 全螢幕固定遮罩（米白色底），中央呈現「Welcome to Our Wedding」、新人姓名「xx & xx」、裝飾細線，以及一顆圓角邊框按鈕「OPEN INVITATION」。
   - 點擊按鈕時：遮罩以 0.8 秒平滑淡出（Opacity 漸變後隱藏），解除 Body 捲動鎖定，並啟動背景音樂與主視覺影片播放。

2. **毛玻璃固定導航列（Fixed Navbar）**：
   - 固定在螢幕頂部，具備毛玻璃效果（半透明白底 + Blur 模糊濾鏡）。
   - 左側：新人自訂 Logo 圖片（高度約 60~70px，需保留防破圖 onerror 處理）+ 新人姓名「xx x xx｜相知相焦」（支援小螢幕自動截斷與防擠壓 `flex-shrink: 0`）。
   - 右側：電腦版顯示錨點連結（About / Details / RSVP）；在手機與電腦版皆常駐一顆 **LINE 官方帳號膠囊按鈕**（純 CSS 繪製的綠色膠囊狀按鈕，內嵌 SVG 圖示，連結至官方 LINE）。

3. **主視覺影片展示區（Hero Video Section）**：
   - 頂部置中展示直式/橫式自適應影片外框（圓角、柔和陰影），內部嵌入 `<video>`。
   - 影片下方展示大字體新人姓名「xx & xx」與日期地點等 Save the Date 資訊。
   - 畫面右下角放置一顆浮動圓形音樂開關按鈕（可手動切換靜音/播放，並切換 Play/Pause SVG 圖示）。

4. **關於我們（About Us）**：
   - 簡短溫馨的文字段落與裝飾細線。

5. **婚禮詳情（Details）**：
   - 雙欄（電腦版）/ 單欄（手機版）卡片展示「時間（When）」與「地點（Where）」。
   - 地點文字支援 `white-space: nowrap` 輔助 class，避免手機版地址中途斷字。

6. **RSVP 智慧出席回函表單（RSVP Section）**：
   - 標題顯示：「RSVP 出席回函」。
   - 表單採用 **無跳轉後台提交技術**（Form 的 target 指向一個隱藏的 `hidden_iframe`，避免送出後跳轉空白頁）。
   - **必填欄位**：姓名（Name）、是否出席（Attendance：單選按鈕）。
   - **智能動態條件連動（核心邏輯）**：
     * **若選「會喔，準時參加」**：展開顯示詳細欄位（關係下拉選單、電子郵件、總出席人數、葷食人數、素食人數、兒童座椅、喜帖需求複選核取方塊）。同時**動態將關係、信箱、總人數設為 required**。
     * **若選「不克參加，送上祝福」**：完全隱藏詳細欄位，並**立刻動態取消隱藏欄位的 required 必填屬性**（避免瀏覽器因隱藏欄位未填而擋住表單送出），並自動將總人數數值設為 `0`。
   - **送出成功回饋**：表單透過 Iframe onload 偵測送出成功，彈出精美 Modal 彈窗，感謝填寫並附上 LINE QR Code 與加入按鈕。

7. **頁尾與 LINE 聯絡區塊（Footer & LINE Section）**：
   - 頁面最下方放置一個置中的 LINE 官方帳號卡片，包含 QR Code 圖片（具備線上 QR 備援 API）與「加入好友取得婚禮第一手消息」按鈕。
   - 最底部版權宣告文字。

### 三、 關鍵技術細節與避坑指南（嚴格遵守）

1. **Safari / iOS 影片自動播放避坑**：
   - 影片標籤必須帶有 `muted`、`loop`、`playsinline`、`webkit-playsinline`。
   - **嚴禁在開場遮罩還完全蓋住螢幕時就呼叫 `video.play()`**！Safari 會因為判定影片不可見而省電凍結在第 1 秒。
   - 正確時序：點擊 Open 按鈕時先取得音訊許可，等遮罩淡出動畫完成（約 800ms 後，影片完全可見於視圖）時，再執行 `video.play()`。
2. **表單提交避坑**：
   - 當賓客選擇不參加時，不可殘留任何隱藏欄位的 HTML5 `required` 驗證，否則瀏覽器會暗中阻擋 Submit，導致按鈕完全無反應。
3. **版面防跑版**：
   - 導覽列內的 Logo 與按鈕需設定 `flex-shrink: 0`。
   - 文字需針對 LINE 內建瀏覽器等超窄螢幕加上截斷（truncate）或動態縮小字級，避免元件被擠出螢幕。
4. **資源預設檔名**：
   - 影片：`Video.mp4`
   - 音樂：`Music.mp3`
   - Logo：`IMG_8776.png`
   - LINE QR Code：`IMG_8755.png`（需附上 `onerror` 自動切換為線上 QR API 的備援機制）。
